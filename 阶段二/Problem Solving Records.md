## 解决问题

### 使用GitBash完成基本流程遇见的问题

1. 在进行初次环境配置 name与"用户名" email与"邮箱"之间没有空格，导致这条设置没生效，加上空格在输入就成功设置好了用户名与邮箱。

2. Clone 时，最初用 git clone 用 ssh 地址复制仓库进行报错，原因：我的 github 账号没有配置 SSH 密钥，后改用 HTTPS 网址克隆。

3. 输入 cd 文件夹时报错显示里面没有叫 Yclsxg 文件夹，原因 Git 仓库后带着（main）已经在仓库里了，可以直接 git add . 
4. 由于自己把克隆到 C 盘上的文件剪切到 E 盘，在 add 时候报错本地文件夹没有 README.md文件被记录成删除，我把克隆文件放回原处，再次输入 git add git commit -m “修改美化主页 README” git push，等了三分钟卡住了。
- 可能原因：
① 网络卡顿，命令悬在那里，不弹出登录窗口
② 凭证管理器问题，或者刚才那次提交已经记录 “删除 README”
