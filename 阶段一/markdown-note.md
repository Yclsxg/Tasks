# 我的markdown学习笔记🤗

## 一、认识markdown
[bilbili学习链接](https://b23.tv/7N35muu)
是一种轻量级标记语言，用简单的纯文本符号来写带格式的文档。
## 二、markdown特点
1. 简单易学：几个符号就能排版。
2. 纯文本通用：啥设备都能打开。
3. 专注内容：不被格式折腾。
4. 易转换：能变网页、PDF、Word。
5. 好管理：方便版本对比和协作。
## 三、markdown核心语法：
标题、文字样式、列表、引用、代码块、
表格、链接、图片
## 四、Markdown 注意事项
1.标记符号使用英文半角

2. #  与标题文字之间保留空格

3.合理使用各级标题，不要跳级

4.文件名小写，以  .md  结尾

5.段落之间空行，排版分层

6.写完预览，检查渲染效果
