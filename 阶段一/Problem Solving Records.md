# 我的问题解决记录😉

本次在学习 GitHub 使用、Markdown 排版、个人主页美化的全过程中，我遇到了多项实操问题，通过一步步排查、学习、实操，全部顺利解决。以下为本次完整问题与解决方案总结：



## 问题 1：不理解 Issue 功能，不知道如何上传图片
### 问题现象
不知道图片链接从哪里获取，不懂 Issue 的用途。
### 解决方法
1. 新建 Issue，可作为图床上传图片；
2. 将图片拖拽或粘贴至输入框自动上传；
3. 上传完成后复制图片地址，用于主页美化。

## 问题 2：使用 `==内容==` 高亮语法失效
### 问题现象
想给文字加颜色高亮，但 GitHub 页面直接显示 `==` 符号，没有任何样式变化。
### 问题原因
GitHub 原生 Markdown **不支持双等于号高亮语法**。
### 解决方法
1. 重点文字使用 `**文字加粗**`；
2. 专业术语使用 `` `行内代码` ``；
3. 需要彩色标签使用徽章语法实现美化效果。


## 问题 3：GitHub 网页经常打不开、加载卡顿
### 问题现象
访问 GitHub 时转圈、超时、图片加载失败。
### 问题原因
GitHub 服务器在海外，跨境网络不稳定、DNS 解析容易出错。
### 解决尝试
1. 校园网切换手机热点更换网络；
2. 通过 CMD ping 获取 IP、修改 hosts 优化解析；
3. 使用网络线路优化工具改善访问。

## 问题 4：分不清 GitHub 用户名 ID、仓库名规则，主页无法生效
### 问题现象
不清楚个人主页为什么需要特殊仓库，不理解 ID 和仓库的关系。
### 解决方法
1. 我的账号 ID：`Yclsxg`；
2. **个人主页生效规则：仓库名必须和用户名完全一致**；
3. 同名特殊仓库的 `README.md` 会自动渲染为个人主页。

## 问题 5：找不到删除仓库的位置
### 问题现象
想删除仓库，但页面找不到删除按钮。
### 问题原因
删除功能藏在页面最底部的**危险区域（Danger Zone）**，位置隐蔽、带有安全二次确认。
### 解决方法
1. 进入仓库 `Settings` 设置页面；
2. 滑动到页面最底端找到危险区域；
3. 点击 `Delete this repository`；
4. 输入完整仓库名确认删除。

> ⚠️ 重要提醒：仓库删除为永久操作，数据不可恢复，操作前必须谨慎。

## 问题 6：排版杂乱、格式不统一、页面不整洁
### 解决方法
统一使用标准 Markdown 规范：
1. 分级标题、有序列表、无序列表规范使用；
2. 重点内容加粗、代码单独标识；
3. 段落留白整齐、适量使用 emoji 美化；
4. 统一链接、术语、语法格式。
